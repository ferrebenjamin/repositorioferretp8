## 🚀 Cómo publicar este sitio en GitHub Pages

1. Subí este repositorio a tu cuenta de GitHub (público).
2. Andá a **Settings → Pages**.
3. En **Branch**, seleccioná `main` y la carpeta `/root`, luego **Save**.
4. Esperá unos minutos: GitHub te va a dar la URL pública
   (formato `https://ferrebenjamin.github.io/nombre-del-repo/`).
5. Actualizá el link de "Sitio en vivo" en este README con esa URL.
